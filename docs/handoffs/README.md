# 인수인계 문서 규칙

- `CURRENT.md`: 다음 세션이 바로 필요한 운영 기준선·진행 중·차단·승인 대기만 유지한다.
- `YYYY-MM.md`: 해당 월의 의미 있는 작업을 오래된 것부터 최신 순서로 맨 아래에 append한다.
- 완료된 작업의 commit·migration·digest·검증·외부 변경은 월별 원장에 남기고 `CURRENT.md`에는
  현재 결과만 승격한다.
- 과거 항목은 고치지 않는다. 정정이 필요하면 새 항목에서 원 항목을 가리켜 정정한다.
- 같은 이력을 `AGENTS.md`나 `PROJECT_PLAN.md`에 복제하지 않는다.
