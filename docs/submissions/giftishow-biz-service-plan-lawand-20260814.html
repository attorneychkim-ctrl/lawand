01 · Service overview

서비스 개요

로앤은 홈페이지와 내부 ERP를 직접 운영하며, 상담 접수부터 사건 담당자 확인, 고객 후기 공개와 답변까지 하나의 인증된 업무 흐름으로 관리하고 있습니다. 이번 연동은 후기 작성자를 대상으로 한 감사 모바일쿠폰을 직원이 수동 발송하는 기능입니다.

연동 목적

고객이 로앤 홈페이지에 실제 이용 경험을 자발적으로 작성한 뒤, 담당 직원이 후기와 고객·사건 정보를 확인하고 사전에 허용된 소액 모바일쿠폰을 감사의 뜻으로 발송합니다. 긍정적인 내용이나 특정 평가를 지급 조건으로 요구하지 않습니다.

1

대상

로앤의 실제 의뢰인 중 홈페이지에 후기를 제출하고 내부 고객 확인이 끝난 사람

2

발송 주체

ERP에 로그인한 권한 있는 직원이 후기 상세에서 수신자와 상품을 확인한 뒤 수동 발송

3

제공 방식

기프티쇼 비즈 API의 MMS 위탁 발송을 통한 일회성 모바일쿠폰 제공

02 · User journey

사용자 흐름과 화면 계획

고객이 쿠폰을 직접 구매하거나 현금화하는 서비스가 아닙니다. 내부 직원만 접근하는 ERP에서 고객 확인과 최종 확인을 거친 단건 발송이 기본입니다.

후기 제출 고객이 로앤 홈페이지에서 자신의 실제 경험을 작성
고객 확인 ERP에서 고객·관련 사건·담당자와 연락처를 확인
상품 선택 관리자가 허용한 소액 상품 중 하나를 직원이 선택
API 발송 수신자 재확인 후 기프티쇼 비즈가 MMS 위탁 발송
결과 기록 거래 ID와 성공·실패·취소 상태를 ERP에 기록

ERP 후기 상세

  • 후기 원문과 홈페이지 공개 상태
  • 고객 전체 이름과 확인된 연락처
  • 관련 사건·주담당자·부담당자 정보
  • 이전 쿠폰 발송 여부와 현재 상태
  • 발송 직원과 처리 시각

쿠폰 발송 모달

  • 허용 상품의 이름·교환처·금액 표시
  • 고객 이름과 전체 전화번호 재확인
  • 발송 메시지와 제공 조건 확인
  • 중복 발송 여부 자동 검사
  • 최종 확인 뒤 한 번만 발송 요청
운영 초기 통제 기준
월 100건 이하, 후기 한 건당 쿠폰 한 장, 3천원~1만원대의 관리자가 승인한 상품만 허용합니다. 자동 발송·불특정 다수 발송·핀번호 재판매·현금 교환 기능은 제공하지 않습니다.

03 · API scope

API 연동 범위

기프티쇼 비즈의 표준 기능을 사용하고, 쿠폰 자체 발행이나 바코드 생성은 하지 않습니다. 운영에 꼭 필요한 조회·발송·상태 관리만 연동합니다.

구분 사용 목적 로앤 ERP 처리
브랜드·상품 조회 발송 가능한 상품명, 이미지, 가격, 유효기간과 유의사항 확인 허용 목록만 정기 동기화하고 직원 화면에는 승인 상품만 노출
비즈머니 잔액 조회 발송 전 구매 가능 여부 확인 잔액 부족 시 발송을 막고 개인정보 없는 오류 표시
쿠폰 단건 발송 확인된 고객 휴대전화로 MMS 위탁 발송 후기별 고유 거래 ID를 만들어 중복 요청 차단
쿠폰 상세·상태 조회 접수·발송·사용 가능 상태와 유효기간 확인 ERP 발송 원장의 최종 결과 보강
재전송·취소 미수신 또는 오발송 건의 운영 대응 직원이 현재 상태와 제공사 허용 조건을 확인한 뒤 수동 실행
로앤 ERP 직원 인증 · 고객/후기 확인 · 최종 발송 확인
→
로앤 Gateway 서버 비밀키 · 멱등 처리 · 발송/결과 원장
→
기프티쇼 비즈 쿠폰 발행 · MMS 위탁 발송 · 상태/취소 처리

중복·불명확 응답 처리

  • 후기 ID와 발송 원장을 기준으로 거래 ID를 유일하게 생성합니다.
  • 타임아웃처럼 실제 발행 여부가 불명확한 경우 동일 상품을 자동 재발송하지 않습니다.
  • 제공사 상태 조회와 취소 가능 여부를 먼저 확인한 뒤 직원이 재전송을 결정합니다.
  • 제공사 오류가 후기 공개·답글 등 다른 ERP 기능을 중단시키지 않도록 독립 처리합니다.

04 · Security & privacy

보안·개인정보 보호 계획

기프티쇼 비즈 API 키와 고객 전화번호는 브라우저에 노출하지 않습니다. 권한 있는 ERP 직원의 요청을 로앤 gateway가 다시 검증한 뒤 필요한 최소 정보만 제공사에 전달합니다.

접근 통제

  • 초대 기반 ERP 직원 계정과 서버 세션 사용
  • 고객·사건·전화번호를 발송 시점에 서버에서 재확인
  • 허용된 후기와 쿠폰 상품에만 발송 가능
  • 직원·시각·대상·상품·결과의 감사 기록 보존

비밀정보 보호

  • API 인증값은 AWS Secrets Manager에 저장
  • ERP 브라우저와 공개 홈페이지에는 인증값 미노출
  • 운영 로그에 전화번호·쿠폰번호·인증 토큰 미기록
  • TLS 통신과 서버별 최소 네트워크 권한 적용

개인정보 처리

  • 수신자 이름과 전화번호는 쿠폰 발송·고객센터 대응 목적에 한정
  • 기프티쇼 MMS 위탁 발송에 필요한 정보만 전달
  • KT알파 처리위탁 내용과 재전송 업무를 개인정보처리방침에 고지
  • 보유기간 종료 또는 처리 목적 달성 시 내부 원장 정리

오남용 방지

  • 후기 한 건당 기본 한 장으로 중복 차단
  • 자동·예약·무제한 대량 발송 미제공
  • 정해진 소액 상품과 월간 운영 상한 적용
  • 오발송은 상태 확인 후 제공사 정책 범위에서 취소
전화번호가 기프티쇼 비즈에 전달되는 MMS 위탁 발송 방식을 사용할 예정이며, 주식회사 케이티알파에 대한 개인정보 처리위탁과 고객센터 조회·재전송 업무를 로앤 개인정보처리방침 및 내부 처리기록에 반영합니다.

05 · Operation policy

운영 정책과 소비자 보호

모바일쿠폰은 좋은 평가를 유도하거나 부정적인 후기를 배제하는 수단으로 사용하지 않습니다. 후기 내용과 쿠폰 제공 여부를 분리하고, 경제적 이해관계가 있는 공개 후기에는 그 사실을 소비자가 쉽게 확인할 수 있도록 표시합니다.

후기 원칙

  • 실제 이용 경험이 있는 고객만 내부 확인
  • 긍정적인 평가·특정 문구·별점을 요구하지 않음
  • 부정적인 의견도 쿠폰 제공에서 차별하지 않음
  • 개인정보와 권리침해 내용 외에는 원문을 임의 미화하지 않음

쿠폰 원칙

  • 발송 전 제공 상품·유효기간·사용처를 확인
  • 수신자에게 재판매·현금화 목적이 아님을 안내
  • 잘못된 번호와 중복 발송을 ERP에서 사전 차단
  • 발송 실패·오발송 문의를 로앤과 제공사 절차로 처리

도입 일정

단계 주요 작업 완료 기준
1. 가입·검토 서비스 소개서 제출, API 이용 범위와 정산 방식 협의, 상용키 신청 기프티쇼 비즈의 연동 승인과 계약 조건 확인
2. 개발 상품 조회, 단건 발송, 결과 조회, 재전송·취소, 잔액 조회 연동 개발 환경의 개인정보 없는 계약 테스트 통과
3. 통제 검증 허용된 내부 수신번호 1건으로 발송·수신·상태·취소 가능 범위 확인 중복 0건, 로그 개인정보 0건, 감사 원장 일치
4. 상용 운영 월 100건 이하의 수동 단건 발송으로 시작하고 실패·잔액·민원을 관찰 정상 발송과 운영 대응 절차 안정화

06 · Applied commercial screen

실 서비스 적용 화면

아래 화면은 로앤 ERP 후기 상세에 실제 구현한 모바일쿠폰 발송 UI입니다. 고객·사건·담당자 확인, 상품 선택, 발송 사유, 안내 문구, 최종 확인의 운영 흐름을 적용했으며 상용 Key 승인 전에는 발송 버튼과 외부 API 호출을 잠가 두었습니다.

심사 제출용 비식별 예시 데이터로 렌더링한 실제 ERP 컴포넌트 화면입니다. 상용 Key 승인 후 기프티쇼 비즈의 승인 상품 조회·발송·결과 조회 API만 서버에서 연결하며, 화면의 고객 확인과 중복·감사 통제는 그대로 유지합니다.
